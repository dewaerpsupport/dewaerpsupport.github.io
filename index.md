# DewaERP Server

DewaERP Server adalah komponen server internal sistem absensi DEWA ERP. Aplikasi ini dipakai server perusahaan untuk menyimpan foto absensi dan salinan cadangan database di Google Drive milik perusahaan. Aplikasi ini tidak tersedia untuk umum.
