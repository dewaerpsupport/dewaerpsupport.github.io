# Kebijakan Privasi DewaERP Server

Berlaku sejak 8 Oktober 2026.

## Tentang aplikasi
DewaERP Server adalah aplikasi internal perusahaan untuk sistem absensi DEWA ERP. Aplikasi ini hanya dipakai oleh akun Google perusahaan, dewaerp.support@gmail.com, dan tidak tersedia untuk umum.

## Data Google yang diakses
Aplikasi hanya meminta izin Google Drive "drive.file". Dengan izin ini aplikasi hanya dapat melihat dan mengubah berkas yang dibuatnya sendiri di Google Drive akun perusahaan, yaitu foto absensi dan salinan cadangan database. Aplikasi tidak membaca berkas lain di Google Drive, email, kontak, atau data Google lainnya.

## Penggunaan data
Berkas tersebut disimpan dan dibaca hanya untuk menjalankan sistem absensi perusahaan. Data tidak dijual, tidak dibagikan kepada pihak ketiga, tidak dipakai untuk iklan, dan tidak dipakai untuk melatih model kecerdasan buatan.

## Penyimpanan dan penghapusan
Berkas disimpan di Google Drive akun perusahaan dan dihapus sesuai kebijakan masa simpan perusahaan. Akses aplikasi dapat dicabut kapan saja melalui https://myaccount.google.com/permissions.

## Data karyawan
Pemrosesan data karyawan, termasuk foto wajah, diatur oleh teks persetujuan yang ditampilkan di aplikasi DEWA ERP.

## Kebijakan Google
Penggunaan informasi yang diterima dari Google API mengikuti Google API Services User Data Policy, termasuk ketentuan Limited Use.
